# Roadmap

NoemaKernel is an early experimental prototype. Metrics are heuristic and should
not be treated as benchmark claims.

## Current prototype

- Bankmap contextual navigation and anchor selection.
- Regressive, progressive and bidirectional context metrics.
- ContextJudge with Semantic Sustainment Score.
- Context reactivation and cognitive reconstruction checks.
- Optional Gemma/Gemini and OpenAI API clients.
- Interactive Gemma terminal for runtime testing.

## Next

- Add an external LLM-as-judge path for ContextJudge calibration.
- Add profile presets for coding, research, teaching and personal-agent flows.
- Separate public docs from internal experiment notes.
- Add reproducible benchmark-style fixtures without benchmark claims.
- Improve packaging with `pyproject.toml` and CLI entry points.

## Later

- Evaluate embeddings for semantic overlap and redundancy.
- Add persistent memory adapters.
- Add richer audit visualizations.
- Publish examples for agent workflows.
